# Курсовой проект 5 - Бэкенд-часть SPA веб-приложения - трекер полезных привычек. 

## Описание
Проект написан на языке программирования Python с помощью фреймворка Django и инструмента Django REST framework.
Фреймворк Django - это набор инструментов, библиотек и правил, которые помогают разработчикам создавать приложения, упрощая и ускоряя процесс разработки. Фреймворк предоставляет структуру, внутри которой можно разрабатывать веб-приложения.
Django использует шаблон проектирования MTV (Model — Template — View).
Django REST framework (DRF) — это библиотека для Python, которая является надстройкой над веб-фреймворком Django и предназначена для создания RESTful API (интерфейсов прикладного программирования). Она предоставляет набор мощных и гибких инструментов, таких как сериализаторы, наборы представлений и аутентификация, которые значительно упрощают разработку и развертывание веб-сервисов, позволяя внешним приложениям взаимодействовать с Django-приложением.
В проекте используется интеграция с сервисом Stripe c помощью API. С документацией по сервису Stripe можно ознакомиться на официальном сайте сервиса [Stripe](https://docs.stripe.com/api).
В проекте используются создание и выполнение отложенных задач с помощью: 
1. Redis - резидентная система управления базами данных класса NoSQL, работающая со структурами данных типа «ключ — значение». Используется как для баз данных, так и для реализации кэшей, брокеров сообщений.
2. Celery — это распределенная очередь задач с открытым исходным кодом, используемая в веб-приложениях на Python для выполнения задач асинхронно, то есть в фоновом режиме.
Так же в проекте реализована интеграция с мессенджером telegtram.

## Описание Моделей
Приложение habit_tracker - модуль моделей models.py:
1. Habit - Описание полей модель - Привычки.

Приложение users - модуль моделей models.py:
1. User - Описание полей модель - Пользователь.

## Описание Контроллеров
Приложение habit_tracker - модуль контроллеров view.py:
1. HabitCreateApiView - Класс реализует интерфейс для создания привычек на основе generics.
2. HabitListApiView - Класс реализует интерфейс для вывода всех привычек на основе generics.
3. HabitUpdateApiView - Класс реализует интерфейс для изменения данных о привычки на основе generics.
4. HabitRetrieveAPIView - Класс реализует интерфейс для отображения данных об одной привычке на основе generics.
5. HabitDeleteAPIView - Класс реализует интерфейс для удаления данных о привычки на основе generics.

Приложение users - модуль контроллеров view.py:
1. UserCreateApiView - Класс реализует интерфейс для создания пользователя на основе generics.

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/NasgDen/Course_Project_5
```
2. В PyCharm установите менеджер проекта poetry.
3. В PyCharm устанавливаем все зависимости проекта из файла pyproject.toml
4. Переименуйте файл .env.sample в .env. Заполните файл конфигурации .env параметрами.

## Использование:

1. В терминале введите: python3 manage.py runserver
2. Запустите Redis командой redis-server.
3. Запустите Celery командой celery -A config worker -l INFO
4. Запустите Celery beat командой celery -A proj beat -l INFO --scheduler django_celery_beat.schedulers:DatabaseScheduler
5. Сервер запускается по адресу: 127.0.0.1:8000
6. Используйте postman для создания и отправки HTTP-запросов к серверу (GET, POST, PUT, DELETE и др.) и анализ их ответов.
